# Goa Assembly Showdown

A browser fighting game with five fighters, three arenas, six specials, solo training, and landscape mobile touch controls.

Open index.html locally, or publish this folder's contents to the root of a GitHub repository and enable GitHub Pages from main / (root).

Keyboard: arrows move/jump/crouch; A punch; S kick; D block; Space special; double-tap left/right to dash; Up+A uppercut; Down+S sweep; Escape pause; F fullscreen; R resets training.
